# Temperature Converter



Project Purpose

This Python program that calculates temperature based on user input.



\## How to Run

1\. Install Python on your computer.

2\. Open the project folder in a terminal.

3\. Run the following command:



git bash

python temperature\_converter.py

&#x20;Example Input/Output

Example input: Enter the values requested by the program.



Example output: The program displays the calculated temperature in desired unit
